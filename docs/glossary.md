# Glossary

| Term | Meaning |
|---|---|
| API | Application Programming Interface; a defined way for software components to communicate |
| BM25 | A lexical ranking function used in information retrieval |
| Embedding | A numerical vector representation of text |
| FastAPI | A Python framework for building APIs |
| Hybrid search | Retrieval that combines lexical and semantic signals |
| LLM | Large Language Model |
| MongoDB | A document-oriented database |
| PostgreSQL | A relational database |
| RAG | Retrieval-Augmented Generation; retrieving relevant information before generating a response |
| Spring Boot | Java framework for building backend applications |
| Top-k | The k highest-ranked retrieval results |
| Sentence-Transformers | Models and tooling for producing sentence embeddings |
| Keycloak | Identity and access management platform |
| SSE | Server-Sent Events; a mechanism for streaming server updates to a client |
