# Placement Syndicate documentation

MkDocs Material documentation site, following the same navigation structure and visual configuration as the Save Vector documentation project.

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Open the local URL printed by MkDocs (normally http://127.0.0.1:8000).

## Build the static site

```bash
mkdocs build --strict
```

The generated site is written to `site/`.
